# victory-day-2026

八月十五日 · 日本无条件投降纪念日纪念网页（抗战胜利 81 周年）。

创作者：小星萤

## 特性

- 单文件静态网页（HTML + CSS，无任何外部依赖、无 JavaScript，可直接保存打开）
- 端庄肃穆、大气沉稳的国风纪念风格：中国红 #9E1010 × 米白 #F8F5F0 × 深黑金
- 思源宋体/系统宋体排版，正式规整、居中布局
- 三段核心正文：历史回望 / 缅怀英烈 / 铭记前行
- 内联 SVG 黑白复古配图：硝烟中的长城插画 + 老式《抗战日报》投降宣告版面
- 极淡长城暗纹背景（SVG data URI，低透明度不抢视觉）
- 仅轻微缓慢的页面淡入效果，无弹窗、无滚动特效、无漂浮动画
- 响应式设计，适配手机与电脑
